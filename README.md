# MOTIBILIS — Academic & Professional Tools Showcase

A premium, fully responsive static web showcase for academic tools, professional software, and developer utilities. Built with Vite, React, Tailwind CSS, and Web Crypto API.

## Features

- 🌟 **Stunning Visual Aesthetics**: Rich gold/black dark theme with 3D starfield canvas, glowing accents, and scroll-driven video backgrounds.
- 📱 **100% Standalone Static SPA**: Zero external server, zero database (MySQL/SQLite), zero external API dependencies.
- 🔐 **PBKDF2 Client-Side Security**: Web Crypto API password protection (310,000 iterations PBKDF2 SHA-256) for admin access with anti-inspection techniques.
- 🌤️ **Live Environmental Weather Widget**: Integrated real-time weather status component.
- 📋 **Software Showcase & Specifications**: Product details, tech stacks, architectural features, and direct website/repository links (no buying/orders).
- 🚀 **GitHub Pages Ready**: Can be deployed instantly to GitHub Pages, Netlify, Vercel, or any static host.

## Tech Stack

- **Framework**: React 19 + Vite 7
- **Styling**: Tailwind CSS v3 + Lucide Icons + Google Fonts (Cinzel & Inter)
- **Animations**: Canvas 3D Starfield + CSS Keyframes
- **Security**: Web Crypto API (PBKDF2 Key Derivation)

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Build for Production (GitHub / Netlify / Vercel)
```bash
npm run build
```
The static production bundle will be generated in the `dist/` directory.
